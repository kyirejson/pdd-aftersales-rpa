# 公开副本整理说明

本文件说明当前仓库与原始生产迁移包之间的差异，便于复核发布边界。

## 保留内容

- `pdd_rpa/` 核心运行源码和静态前端；
- `tests/` 自动化测试；
- `config/rules.json` 示例规则；
- `requirements.txt` 与 `requirements.lock.txt`；
- 启动脚本和工程诊断脚本；
- 架构、安全、迁移和界面文档；
- 由合成任务生成的界面截图。

## 移除内容

- 生产 SQLite 数据库、日志、锁文件和测试数据库；
- 全部业务截图、登记表、导出文件和运行证据；
- Edge 用户目录、浏览器登录态和迁移备份；
- 控制台访问配置与会话密钥；
- `.venv/`、`scripts/node_modules/` 和离线安装包；
- 一键生产执行入口和迁移打包器。

## 脱敏处理

- 真实店铺替换为“示例书店 A/B/C……”和“示例天猫旗舰店”；
- 仓库、供应商、商品关键词、消息群组和城市均替换为占位值；
- 内部钉钉文档地址替换为 `example.com` 占位地址；
- 本机用户路径替换为 `<USER_HOME>`；
- 订单号、运单号和手机号形态的测试数据被替换为合成值；
- 截图使用临时演示数据库重新生成，不使用原始截图。

## 前端演示副本

`docs/app/` 是项目真实静态前端的展示副本，保留原页面结构、样式和按钮交互。它只额外加载 `mock-api.js`，用合成的只读数据响应原页面已有的 API 请求，不连接真实店铺、数据库、浏览器登录态或桌面客户端。`docs/app/demo-responsive.css` 仅补充小屏布局，不增加业务功能。

## 发布版行为

- 默认 `OBSERVE`；
- 默认关闭真实外部写操作；
- 首次初始化自动生成本地随机控制台密码；
- 不包含可直接触发真实退款或真实消息发送的脚本入口。

## 复核方式

在仓库根目录执行：

```powershell
git status --short
git ls-files
python -m pytest -q
```

推送前还应检查暂存区中不存在 `runtime/`、真实配置、数据库、截图证据、依赖目录、日志或任何真实业务标识。
