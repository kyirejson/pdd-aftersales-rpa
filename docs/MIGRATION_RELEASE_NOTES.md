# 本版迁移变化说明

本版以 2026-08-22 迁移包的 `SHA256SUMS.txt` 为基线，打包时会自动生成逐文件的 `版本变更清单.md`。以下是需要迁移人员重点关注的功能变化。

## 业务范围变化

- 新增千牛“示例天猫旗舰店”独立 Edge、未收货退款扫描、详情读取、旺店通查询和处理链路；
- 拼多多售后流程补充分页、列表物化、登录恢复、弹窗清理、详情定位、物流读取、同意/驳回安全核算与失败恢复；
- 钉钉登记由单一示例自营仓目标扩展为示例自营仓和示例代发分销两个目标；
- 圆通登录凭据改为 Windows DPAPI 本机保存，明确不随迁移包复制；
- 控制台增加访问口令、千牛入口、路由设计与更细的运行状态展示。

## 迁移机制变化

- Manifest 升级为格式 v2，增加当前配置摘要、数据库表/状态分布、目录分区统计、基线差异和告警；
- 继续使用 SQLite 在线备份生成一致性快照，部署副本强制全局暂停与 `STOPPED`；
- 离线 Python 与 wheelhouse 优先复用上一版已验证资产，并用 `pip --dry-run --ignore-installed` 检查依赖闭包；
- 新增 `SHA256SUMS.sha256`，先验证校验清单自身，再验证每个迁移文件；
- 新增 ZIP64 封装、ZIP 完整性测试及旁置 `.zip.sha256`；
- 新增分项验收、回滚手册、内容清单和人工验证模板；
- 目标机准备脚本新增千牛独立用户目录，预检新增千牛和两个钉钉目标的阻断项。

## 安全提醒

当前项目属于生产自动化版本，配置允许真实业务动作。迁移副本的核心安全门是数据库全局暂停；迁移人员必须按验收清单确认 `global_paused=true`，并在源电脑完全停止、目标机所有只读检查通过后才解除暂停。
